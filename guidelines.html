BOT GUIDELINES

Use Nightfall
responsibly.

These guidelines keep the bot safe, predictable and useful across communities.

1. Respect permissions

Only grant Nightfall the permissions required for the features you enable. Review role hierarchy and channel overrides after setup.

2. Protect staff tools

Limit setup, moderation and security controls to trusted staff. Never share dashboard credentials, API secrets or bot tokens.

3. Use automation carefully

Anti-raid, anti-nuke, anti-link and automatic punishment features can affect real members. Configure thresholds and exemptions before enabling them.

4. Keep appeals available

If your server uses bans or jail, configure an appeal destination so members have a clear route to contact staff.

5. Respect Discord rules

Use Nightfall in accordance with Discord's Terms, Community Guidelines and applicable laws. Nightfall is a server-management tool, not a replacement for moderation judgment.

6. Developer responsibility

Only authorized Nightfall developers should publish bot-wide announcements, deploy updates or change shared infrastructure.
