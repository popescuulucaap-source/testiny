RULES & GUIDELINES

Keep Nightfall useful and safe.

Use the bot responsibly and configure destructive systems carefully.

Server owners

Only give Nightfall the permissions required for the features you enable. Review roles, channels and security settings after setup.

Moderation

Use bans, kicks, timeouts and warnings consistently with your server rules. Staff should review automated actions when appropriate.

Security

Anti-raid and anti-nuke systems can perform destructive actions. Test them in a controlled server before enabling them broadly.

Privacy

Do not use Nightfall to collect sensitive information through tickets, verification or feedback forms.
